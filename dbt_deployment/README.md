# dbt Deployment

Deploys a dbt project locally using Docker with PostgreSQL as the data warehouse. Runs analytics models on the impression data generated by the web server API.

## Prerequisites

- Docker and Docker Compose installed
- Web server running locally (see `../web_server_local/`)
- Shared Docker network (`data-processing-network`) — created automatically by `deploy.sh`

## Directory Structure

```
dbt_deployment/
├── Dockerfile              # dbt-postgres Docker image
├── docker-compose.yaml     # PostgreSQL + dbt services
├── deploy.sh               # Deployment management script
├── init_db.sql             # Database schema initialization
├── load_data.py            # Loads data from web server API into PostgreSQL
├── README.md
└── dbt_project/
    ├── dbt_project.yml     # dbt project configuration
    ├── profiles.yml        # Connection profiles
    └── models/
        ├── staging/
        │   ├── stg_impressions.sql     # Cleaned raw impressions
        │   └── schema.yml              # Source + staging tests
        ├── intermediate/
        │   └── int_impressions_aggregated.sql  # Aggregated by user/impression/page
        └── analysis/
            ├── funnel_analysis.sql     # Event funnel conversion rates
            ├── page_type_summary.sql   # Page type statistics
            ├── user_engagement.sql     # User-level engagement metrics
            ├── hourly_traffic.sql      # Hourly traffic patterns
            └── schema.yml              # Analysis model tests
```

## Quick Start

```bash
# 1. Start the web server (in another terminal)
cd ../web_server_local && ./deploy.sh up

# 2. Start PostgreSQL
./deploy.sh up

# 3. Load impression data from the API
./deploy.sh load-data --all

# 4. Run dbt models
./deploy.sh run

# 5. Run dbt tests
./deploy.sh test
```

## Commands

| Command | Description |
|---------|-------------|
| `./deploy.sh up` | Build and start PostgreSQL |
| `./deploy.sh down` | Stop and remove containers |
| `./deploy.sh restart` | Restart all services |
| `./deploy.sh status` | Show container status |
| `./deploy.sh logs` | Tail container logs |
| `./deploy.sh run` | Execute `dbt run` (build all models) |
| `./deploy.sh seed` | Execute `dbt seed` |
| `./deploy.sh test` | Execute `dbt test` |
| `./deploy.sh load-data --all` | Load all page types for current date/hour |
| `./deploy.sh load-data --page_type 1 --date 2026-01-01 --hour 10` | Load specific data |

## Models

### Staging
- **stg_impressions**: Cleans raw impression data, casts types, derives event timestamp

### Intermediate
- **int_impressions_aggregated**: Aggregates events by user_id/impression_id/page_type (mirrors the Spark aggregation job)

### Analysis
- **funnel_analysis**: Conversion rates through event stages a→f by page type
- **page_type_summary**: Volume, unique users, avg funnel depth, conversion percentages per page type
- **user_engagement**: Per-user metrics including total impressions, funnel depth, most engaged page type
- **hourly_traffic**: Hourly impression volume and engagement by page type

## Connecting to PostgreSQL

```bash
psql -h localhost -p 5433 -U dbt -d data_processing
# Password: dbt
```

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `DBT_POSTGRES_HOST` | `localhost` | PostgreSQL host (for load_data.py) |
| `DBT_POSTGRES_PORT` | `5433` | PostgreSQL port (for load_data.py) |
| `DBT_POSTGRES_DB` | `data_processing` | Database name |
| `DBT_POSTGRES_USER` | `dbt` | Database user |
| `DBT_POSTGRES_PASSWORD` | `dbt` | Database password |
| `API_BASE_URL` | `http://localhost:8000` | Web server API URL |
